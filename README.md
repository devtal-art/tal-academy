# TAL Academy – React Frontend (Stage 1)
Requires Node >= 20.19 (tested path: Node 22/24). React 19, Vite 8, React Router 7, Framer Motion.
    npm install
    npm run dev      # local
    npm run build    # production build in dist/
- WhatsApp number + email: src/data.js
- All courses, modules, services, FAQ: src/data.js
- Lead form: src/api.js (Stage 1 opens WhatsApp; Stage 2 call your backend)
- Images: src/assets/images/*.svg (replace with your photos, update imports in src/data.js)
- Colours: src/styles.css (--bl, --bl2)
